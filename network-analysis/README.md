# Network Analysis

Packet-capture and traffic-analysis labs focused on understanding normal behaviour, identifying anomalies, and communicating evidence clearly.

## Focus Areas

- Wireshark display filters and protocol analysis
- TCP/IP, DNS, HTTP/S, DHCP, and ICMP behaviour
- Traffic baselining and anomaly identification
- Suspicious connection and indicator extraction
- Evidence timelines and investigation summaries

## Recommended Lab Format

1. Objective
2. Capture source and environment
3. Filters and analysis steps
4. Key packets or evidence
5. Findings and indicators
6. Conclusion and lessons learned
