# Detection Labs

Detection-engineering exercises that turn suspicious behaviour into testable analytics and explain how each rule performs.

## Focus Areas

- Detection hypotheses and threat behaviours
- Log-source and telemetry requirements
- SIEM queries and rule logic
- Positive and negative test cases
- False-positive analysis and tuning
- MITRE ATT&CK mapping
- Analyst triage guidance

## Recommended Lab Format

Record the hypothesis, required data, rule or query, test procedure, expected results, tuning decisions, and investigation guidance.
