# Phishing Analysis

Safe, evidence-led analysis of simulated or authorised phishing messages, with emphasis on triage, indicator extraction, and user-focused recommendations.

## Focus Areas

- Sender, reply-to, and routing-header review
- SPF, DKIM, and DMARC results
- URL and domain analysis
- Attachment metadata and safe handling
- Indicator-of-compromise extraction
- Verdict, containment, and user guidance

## Safety

Use only authorised training samples. Defang links and indicators in public write-ups, and never publish live credentials or personal information.
