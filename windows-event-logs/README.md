# Windows Event Logs

Endpoint investigation labs using Windows Event Viewer, exported logs, and SIEM queries to explain authentication, process, and PowerShell activity.

## Focus Areas

- Successful and failed authentication events
- Account and group changes
- Process creation and command-line evidence
- PowerShell operational logging
- Timeline reconstruction and event correlation
- Clear escalation and remediation notes

## Recommended Lab Format

Document the question, data source, relevant event IDs, filters or queries, evidence, conclusion, and any limitations.
